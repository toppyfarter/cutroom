# Cutroom YouTube Downloader

An app for downloading YouTube video/playlist

## Install and run

**There're 2 ways to install:**

1:grab compiled executable in Release tab and run it

2:download the zip of repository and then open launcher.py

(REMEMBER TO DOWNLOAD PYTHON [HERE](https://www.python.org/ftp/python/3.15.2/python-3.15.2-amd64.exe))
